# EXP-006 — Is the C_base feature set tradeable?

**VERDICT: REJECTED — but on one criterion, not on all of them.**

`gradient_boosting` on the 27-feature `C_base` set clears three of the four
candidate gates. It fails the fourth: **net Sharpe −0.102** at the declared
10 bp half-spread. It is the closest anything has come in six studies, and it is
still not promotable.

Two things in this report contradict what I predicted before running it. Both
are stated in §2 rather than buried.

---

## 1. Why this experiment existed

EXP-005 answered "does any additional data source add information?" with a clear
no, and left one thing unresolved as a side effect of how the ablation ran: **the
arms were never costed.** They measured rank information only — no backtest, no
book, no turnover, no Sharpe, no factor attribution.

So `C_base` finished EXP-005 with the highest observed IC (+0.0290, t +2.66) and
a completely unknown economic profile. That is a bad place to stop, and EXP-006
put the frozen specification through the full apparatus.

| | |
|---|---|
| Experiment | `EXP-006`, fingerprint `6f8703469aec28e5` |
| Feature set | **frozen** to EXP-005's `C_base` arm — price, volatility, volume, macro |
| Features | **27 of 57** available columns |
| Panel | 506,374 rows · 977 symbols · 625 dates · hash `95473c9f6cd896d6d3be5dd563cc156a` |
| Runtime | 1,915 s (32 min), 6 workers, peak ~6.2 GB |
| Trials | 17 declared, 139 prior, **156 cumulative** |
| Holdout | untouched; contract NOT ARMED |

Nothing was tuned. No threshold moved.

## 2. Where my pre-registered prediction was wrong

The definition recorded this before the run:

> C_base will not survive. Its t-statistic was the maximum of 42 configurations
> and should regress toward the single-model value; its gross Sharpe should be
> negative, as every configuration measured across five studies has been.

**Both halves were wrong, and for different reasons.**

**The t-statistic did not regress — and could not have.** EXP-006 refits the
identical model on the identical folds with the identical seed, so it reproduced
+2.66 exactly. Regression to the mean applies to a *new sample*; this was not
one. The prediction was badly reasoned, not merely unlucky. What EXP-006 actually
supplies is the missing economics, and that is the only thing it can supply.

**The gross Sharpe was not negative.** It is **+0.384** — the first positive
gross Sharpe from a learned model anywhere in this project. Every configuration
in EXP-004 and EXP-005 lost money before costs; this one does not.

Recording a wrong prediction is the point of making one. It is also the reason
the conclusion below is not simply the previous conclusion restated.

## 5. The uncomfortable part: it is cost-assumption dependent

| half-spread | gross SR | **net SR** | cost share | max DD |
|---|---|---|---|---|
| 1 bp | +0.384 | **+0.169** | 56% | −18.6% |
| 3 bp | +0.384 | **+0.108** | 72% | −20.9% |
| 5 bp | +0.384 | **+0.048** | 87% | −23.2% |
| **10 bp** | +0.384 | **−0.102** | 127% | −28.8% |
| 20 bp | +0.384 | −0.403 | 205% | −45.2% |

**Net Sharpe is positive at 1, 3 and 5 bp and crosses zero between 5 and 10.**

That is not a reason to celebrate; it is a reason to be careful. The half-spread
is the **single largest acknowledged uncertainty in the whole pipeline** — the
equity dataset carries no bid/ask, so it is a parameter, not an observation. A
result whose sign depends on that parameter is a result about the parameter.

For a top-250-by-dollar-volume universe, 5 bp is arguably defensible and 10 bp is
conservative. But "the conclusion flips at a spread we cannot measure" is a
weaker claim than "the model works," and it must not be rounded up to the latter.

Turnover is the mechanism: **20.1× annualised**, against 5.6× for
`baseline_low_volatility`. The gross edge is real and small; the trading required
to harvest it is what consumes it.

## 6. There is no alpha

Six-factor attribution (Fama-French 5 + momentum) — the only place this project
permits the word:

| | |
|---|---|
| alpha, annualised | **+0.25%** |
| alpha t-statistic | **+0.047** |
| significant | **No** |
| R² | 0.039 |

**An alpha t of +0.05 is zero.** Whatever gross edge exists is not distinguishable
from zero once the factor model is fitted, and the low R² says the factors do not
explain the returns either — the returns are simply too small and too noisy to
attribute. A gross Sharpe of +0.38 with an alpha t of +0.05 is a weak signal, not
a discovery.

For comparison, `baseline_momentum` — a factor published in 1993, at 7.4×
turnover — has alpha t **+0.44**, nearly ten times larger and still not
significant.

## 7. A control that changed its answer

| Control | EXP-005 (57 features) | EXP-006 (27 features) | Role |
|---|---|---|---|
| `shuffled_within_date` | −0.0037, t −1.07 | −0.0054, t −1.48 | blocking — **PASS** |
| `permuted_symbols` | +0.0029, t +0.95 | −0.0021, t −0.61 | blocking — **PASS** |
| `shifted_forward` | +0.0170, t +1.30 | **+0.0287, t +1.88** | diagnostic — **finding** |

Both blocking controls pass, so the pipeline is not manufacturing signal.

But look at the diagnostic against the real result:

```
real target        IC +0.0290
target displaced 4 rebalance periods   IC +0.0287
```

**The model predicts a target displaced ~20 sessions almost exactly as well as
the real one.** That is the signature of a slow-moving, persistent signal — not a
21-day edge. It is consistent with the alpha t of +0.05: the model is tracking
something that decays over months, which is the same thing momentum captures, and
which the factor model therefore has no trouble absorbing.

This is not evidence of leakage — a leak-free passthrough baseline shows the same
pattern, which is why the control was reclassified as diagnostic in EXP-004. It
is evidence about *what kind* of signal this is, and the answer is "a slow one."

## 10. What this actually establishes

**Not** "we found an edge." **Not** "there is nothing there." Something narrower
and more useful than either:

1. **A smaller feature set is a better specification.** 27 price-derived features
   beat 57 across every model. EXP-005 showed adding data hurt; EXP-006 confirms
   the reduced set holds up when costed.
2. **The gross edge is real but small.** +0.384 gross Sharpe, +2.66 t. This is
   the first time either has been true here.
3. **Turnover eats it.** 20.1× annualised turnover converts a positive gross
   Sharpe into a negative net one somewhere between a 5 and 10 bp half-spread.
4. **There is no alpha.** t = +0.047. A 1993 factor has ten times more.
5. **The signal is slow.** It predicts a 20-session-displaced target as well as
   the real one.

The actionable reading: if this line is worth pursuing, the next question is
**turnover reduction**, not model capacity — a slow signal traded 20× a year is
paying for churn it does not need. That would be a new pre-registered experiment
with its own trial budget, and its result would be as likely negative as this one.

## 11. Holdout

**DO NOT ARM.**

A holdout confirms a candidate that development evidence has already made
plausible. `gradient_boosting` on C_base fails the net-Sharpe gate, produces no
alpha, and depends on an unmeasurable cost parameter for its sign. Spending a
single-use 252-session reserve on it would consume the project's last independent
test to answer a question the development set has already answered.
