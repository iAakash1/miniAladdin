## 2. What EXP-002 got wrong, and what it cost

`pandas.merge_asof` discards the left frame's index and returns a fresh
`RangeIndex`. Both as-of joins relied on `sort_index()` to restore row order —
a no-op on a replaced index — so values were written back **positionally into a
differently-ordered frame**. 12 of 39 features carried other rows' values, some
from later dates.

**The clean re-run quantifies the damage exactly.** The three single-feature
passthrough baselines were never affected; they reproduce to the digit. Every
model that consumed the full feature set degraded:

## 3. Additional corrections found and fixed during EXP-004

### 3.1 Unenforced chronological ordering — fixed

Every rolling feature and every forward label is computed over **row order**,
not dates. Passing a date-shuffled frame to `compute_symbol_labels` or to any
price feature produced values that did not match the correctly-ordered answer
once realigned by date — silently.

Callers all happened to sort first, so nothing was affected. But relying on
every caller to remember is the arrangement that produced the `merge_asof`
defect. `require_chronological` now enforces strict date-ascending order with
no duplicate sessions at both boundaries.

### 3.2 Control fold geometry — fixed, and it failed loudly

The negative controls built their trading calendar from the **strided** panel
(every 5th session, 625 dates) rather than the full session calendar (~3,100).
`build_plan` refused outright. Had it silently produced a different fold layout,
the controls would have been evaluated on different folds than the models and
would have been controls for nothing. Regression test added.

### 3.3 PBO destroyed by a degenerate configuration — fixed

`baseline_historical_mean` predicts a constant, so it forms a quantile book on
only 12 rebalance dates. Inner-joining it against every other model collapsed
the matrix below the 32 rows CSCV needs, and PBO silently reported `None`.
Degenerate configurations are now excluded before aligning, and named in the
output. PBO is now computed: **0.171** (primary target) and **0.286**.

---

### 3.4 Feature audit could silently emit an empty document — fixed

Features register themselves as an import side effect. `build_feature_audit()`
did not import them, so calling it from anywhere that had not already imported
the feature modules produced a clean, well-formed audit reporting **zero
features** — a document whose entire purpose is to prove all 67 were examined,
asserting there was nothing to examine. The imports are now forced inside the
builder and the empty case raises.

### 3.5 `production_candidate` checked evidence but not what it said — fixed

`PROMOTION_GATES` verifies that a walk-forward, a methodology, a baseline
comparison, a backtest and a factor attribution all *exist*. Numeric bars were
only consulted at `production`, and those read the holdout — which must stay
locked. So a model could arrive with a complete evidence bundle stating that it
loses money and still be labelled a production candidate.

EXP-004's best model is exactly that bundle. `CANDIDATE_THRESHOLDS` now applies
validation-side bars at candidacy — |IC t| ≥ 2, net Sharpe > 0, **gross Sharpe >
0**, and beating the best baseline — and an unrecorded value counts as unmet.
`eligible_for` applies the same bars, so it can no longer advertise a status
that `promote()` would refuse.

Every EXP-004 entry is now eligible for `validated` and nothing further:

```
random_forest@2.0:fwd_rank_21
  unmet: ic_t_stat +1.911, net_sharpe -0.598, gross_sharpe -0.276
  eligible_for: ['validated']
```

Nothing was promoted. Production count is **0**.

### 4.2 Negative controls

|---|---|---|---|---|
| `shuffled_within_date` | −0.0035 | −1.07 | **blocking** | **PASS** |

The two blocking controls destroy the feature-outcome pairing while leaving

### 4.3 The control that was reclassified — disclosed in full

`shifted_forward` fired on the first attempt and **aborted the run before a
single model was fitted**. Rather than assume either leakage or innocence, the
displacement was measured against passthrough baselines that provably cannot
leak — `mom_252_21_xs` and `vol_63_xs` are backward rolling windows with no
fitting, no join and no as-of merge:

| Model | real target | shifted 4 periods | retained | shuffled |
|---|---|---|---|---|
| `baseline_momentum` | +0.0158 | +0.0194 | **122%** | +0.0007 |
| `baseline_low_volatility` | +0.0209 | +0.0127 | 61% | +0.0050 |

A leak-free model retaining its IC on a target displaced 20 sessions means the
control measures **horizon persistence**, not contamination: 12-1 momentum is
documented to act over 3–12 months. It was reclassified from blocking to
diagnostic.

**This is a change to a gate after that gate fired, and it is disclosed as
one.** It rests on independent measurement from a model that cannot leak, not
on the gate being inconvenient — but a reader should weigh it knowing the
sequence. Artifact: `experiments/EXP-004/shift_diagnostic.json`.

### 4.4 Holdout isolation

Asserted **before any model is constructed**, and again by the preflight:

```
holdout 2025-08-28 -> 2026-08-28 (252 sessions) LOCKED; last fold ends 2025-05-09
```

111 sessions of separation. Integrity cutoffs are additionally capped strictly
below the holdout start, so no matrix built during this experiment extends into
it.

## 7. Why this is NO EVIDENCE OF EDGE

Six gates, applied to the best model on the primary target:

| Requirement | Result |
|---|---|
| IC distinguishable from zero (\|t\| > 2) | **FAIL** — `random_forest` t = +1.91 |
| Beats the best free baseline | **MARGINAL** — +0.0238 vs +0.0209, a 0.003 gap; neither significant |
| Net Sharpe > 0 after costs | **FAIL** — −0.60 at 10 bp |
| Gross Sharpe > 0 *before* costs | **FAIL** — −0.28 |
| Six-factor alpha significant | **FAIL** — t = −1.34 |
| Survives the trial count (DSR > 0.95) | **FAIL** — 0.000 against 80 cumulative trials |
| Holds up in the one regime with enough data | **FAIL** — IC +0.007, t +0.54 over 267 dates (§9) |

**The decisive fact is the gross Sharpe.** `random_forest` has a positive rank
IC and a **negative gross Sharpe of −0.28** — it loses money *before a single
basis point of cost*. Positive ranking information that does not survive being
turned into a dollar-neutral book is not tradeable at any cost assumption. The
cost sweep confirms there is nothing to rescue:

| half-spread | gross SR | net SR | turnover | cost share |
|---|---|---|---|---|
| 1 bp | −0.276 | −0.418 | 18.0 | 51% |
| 3 bp | −0.276 | −0.458 | 18.0 | 66% |
| **10 bp** | −0.276 | **−0.598** | 18.0 | 117% |
| 20 bp | −0.276 | −0.798 | 18.0 | 189% |

The only model with a positive gross Sharpe is `baseline_momentum` (+0.14),
whose net Sharpe is −0.02 — indistinguishable from zero, and it is a factor
published in 1993.

## 9. Regime analysis — and where the IC actually comes from

Two different counts matter, and conflating them would overstate the evidence.
The **dataset census** covers all 625 panel dates; the **validation census**
covers only the 404 dates inside a validation fold, and those are the only ones
any model metric is computed on.

| Regime | Dataset dates (625) | Validation dates (404) | Quotable? |
|---|---|---|---|
| low-volatility bull | 426 | **267** | yes |
| high-volatility bull | 136 | 85 | **INSUFFICIENT EVIDENCE** |
| stress | 34 | 33 | **INSUFFICIENT EVIDENCE** |
| low-volatility bear | 10 | 10 | **INSUFFICIENT EVIDENCE** |
| high-volatility bear | 19 | 9 | **INSUFFICIENT EVIDENCE** |

The floor is 200 validation dates. Labels span 21 sessions and rebalances are 5
apart, so a regime's independent block count is roughly `dates × 5 / 21`: 267
dates is ~64 blocks, 85 is ~20, and 9 is ~2. Below the floor a regime reports
its count and nothing else, in the artifact and in the registry.

### The finding that matters

`random_forest`, the best model on the primary target, broken out by regime:

| Regime | Validation dates | IC | t | Quotable? |
|---|---|---|---|---|
| **low-volatility bull** | **267** | **+0.0071** | **+0.54** | **yes** |
| high-volatility bull | 85 | +0.0607 | +2.12 | no |
| stress | 33 | +0.0675 | +1.58 | no |
| high-volatility bear | 9 | +0.0873 | +2.04 | no |
| low-volatility bear | 10 | −0.0460 | −0.53 | no |

**In the only regime with enough evidence to quote — 66% of the sample — the
model's IC is +0.007 with a t-statistic of +0.54.** That is nothing.

The headline +0.0238 is carried almost entirely by regimes of 9 to 85 dates.
The two t-statistics above +2.0 in the whole experiment are a 9-date and an
85-date bucket, and a +2.04 computed on nine dates is the single most
cherry-pickable number this pipeline produces. Reporting the regime split
without its date counts would have turned a null result into a story about a
model that "works in volatile markets."

This does not mean the model has no regime dependence. It means **this sample
cannot tell us**, and one year of holdout — which is 252 sessions covering
mostly one regime — will not change that.

## 13. Should the holdout be opened?

**No.**

A holdout is spent to confirm or refute a candidate that the development
evidence has already made plausible. There is no such candidate:

* the best model fails on \|t\|, on gross Sharpe, on net Sharpe, on alpha and on
  the trial-count correction;
* it beats the best free baseline by 0.003 IC, with neither result significant;
* the only positive gross Sharpe belongs to a 1993 factor, and its net Sharpe is
  zero;
* what IC it does have is concentrated in regimes of 9 to 85 validation dates —
  in the one regime with enough data to quote, it is +0.007 at t +0.54.

Spending a single-use 252-session holdout to test a model that already fails
every development gate would waste it and answer nothing. `HOLDOUT_CONTRACT.md`
remains **NOT ARMED**, and `python -m src.quant.study.holdout --preflight`
refuses on `contract_armed`.

## 14. What this experiment did establish

The negative result is the headline, but it is not the only output. The
apparatus is now, as far as measurement can establish:

* **leakage-tested** — truncation invariance clean over 1.39M rows × 67 features
  at four cutoffs; two blocking negative controls returning ≈ 0;
* **reproducible** — one command, a hashed definition, a persisted artifact,
  seed and dependency versions recorded;
* **point-in-time correct** — corporate actions at ex-date, earnings gated on
  announcement date with the session rule, macro lagged, every fitted transform
  scoped to a fold or a date, chronological ordering enforced at the boundary;
* **honestly accounted** — 80 cumulative evaluations, void results retained,
  a reclassified gate disclosed with its evidence and its sequence.

That is what makes the negative trustworthy, and it is the precondition for any
future experiment being worth running.

**Category: NO EVIDENCE OF EDGE.**
