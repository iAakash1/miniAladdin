# Model Lab multiple-testing account

MODEL-LAB-001 deliberately searches many estimators, so a large raw t-statistic
is not confirmatory evidence. The SQLite ledger retains the complete population:
complete, failed, invalid, pruned, resource-limited and blocked trials.

The final report must count model families, hyperparameter configurations,
feature sets, ensemble trials, seeds and outer fits. It will report the full IC
distribution and, where inputs support them, Deflated Sharpe Ratio and
Probability of Backtest Overfitting. White's Reality Check or Hansen SPA will
be included only if their dependence/bootstrap implementation is defensible;
absence is preferable to a decorative p-value.

No statement of the form “t > 2 proves skill” is allowed. Any shortlist remains
exploratory and must be frozen before a separate replication design.
